Conocé lo que incluye.

Una base para crear una pequeña arena de extracción para un jugador. La demo Núcleo 90 combina recolección de núcleos, drones de patrulla y un portal de salida.

El paquete está pendiente de revisión por Unity Asset Store. Todavía no tiene un enlace público de compra confirmado.

La portada cartoon es una ilustración promocional del sistema.

  • ✦Demo con movimiento, dash y patrullas
