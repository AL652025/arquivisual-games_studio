Guía de Desarrollo

CÓMO PUBLICAR TUS JUEGOS EN ESTA WEB

Integra fácilmente todos los proyectos que hagas en GDevelop o en itch.io para que tus jugadores puedan jugarlos online o descargarlos con 1 solo clic.

1

Exporta desde GDevelop

En GDevelop ve a Archivo → Exportar → Web (HTML5). Guarda los archivos generados en una carpeta dentro de este proyecto:

/arquivisual-games/games/nombre-de-tu-juego/
2

Vincula con Itch.io

Sube el archivo comprimido (.zip) o el instalador (.exe) a tu cuenta de itch.io. Copia el enlace de tu juego o el widget iframe para que aparezca directamente en tu web.

https://tu-usuario.itch.io/tu-juego
3

Regístralo en games-data.js

Abre js/games-data.js y añade los datos de tu juego (título, descripción, enlaces de descarga y juego online). La web lo detectará y mostrará automáticamente.

{ id: "mi-nuevo-juego", title: "Mi Juego", engine: "GDevelop", ... }
4

Sube a GitHub con 1 Clic

Con Git conectado a tu cuenta de GitHub, sube los cambios para que se actualice tu sitio web público en GitHub Pages de forma gratuita y con HTTPS.

git add . && git commit -m "Nuevo juego" && git push
